## 项目部署方法

### 1. 下载项目

在 GitHub 项目页面点击绿色的 **Code** 按钮，选择 **Download ZIP**，下载后解压。

也可以使用 Git 命令：

```bash
git clone https://github.com/dyuxin476-dev/-.git 新生计算机入门实践
```

### 2. 进入项目文件夹

```bash
cd 新生计算机入门实践
```

如果已经在项目文件夹中打开终端，可以跳过这一步。

### 3. 安装依赖库

```bash
pip install -r requirements.txt
```

### 4. 准备输入图片

将提供的图片放入项目中的 `images` 文件夹，并命名为：

```text
images/input.jpg
```

### 5. 运行基础图片处理程序

```bash
python main.py
```

程序会读取 `images/input.jpg`，默认进行黑白处理，并生成：

```text
images/output.jpg
```

### 6. 尝试其他处理模式

#### 6.1 黑白效果

将图片转换为黑白色调，便于观察图片颜色变化。

```bash
python main.py --mode gray
```

#### 6.2 模糊效果

对图片进行模糊处理，使图片细节变得不清晰。

```bash
python main.py --mode blur
```

#### 6.3 变亮效果

提高图片整体亮度。这个模式使用 NumPy 对图片像素进行运算。

```bash
python main.py --mode brighten
```

### 7. 生成图片对比图（拓展）

先运行一次图片处理程序，再运行：

```bash
python compare.py
```

程序会生成：

```text
images/comparison.png
```

这一步属于拓展内容，不影响基础实践题完成。

## 使用的库说明

| 库名 | 版本 | 用途 | 在本项目中的功能 |
|---|---:|---|---|
| **Pillow** | ≥10.0.0 | 图像处理库 | 打开、修改和保存图片，完成黑白和模糊处理 |
| **NumPy** | ≥1.24.0 | 科学计算库 | 将图片转换为像素数组，完成亮度调整和像素运算 |
| **Matplotlib** | ≥3.7.0 | 绘图库 | 生成原图与处理结果的对比图 |

## Git 基础命令了解

本题不要求提交代码，但可以简单了解以下命令：

```bash
git status              # 查看项目当前状态
git add .               # 准备保存修改
git commit -m "说明"    # 保存一次修改记录
git push                # 上传修改
```

Git 用来管理项目的修改历史，GitHub 用来保存和分享项目。二者经常配合使用，但不是同一个东西。
