# 示例同学的实验记录

## 1. 使用环境

- 操作系统：Windows
- Python 版本：3.11

## 2. 使用的命令

```bash
git clone 项目地址
cd 新生计算机入门实践
pip install -r requirements.txt
python main.py --mode gray
```
